## Dictate-Diktat-arm64.apk – diktat

diktat 6.4.0, gebaut aus dem Zweig `ccr-f00e4660-7onxml` (Commit 9ab7073). Nur für private Tests.

- App-Name „diktat“, Paketname `app.diktat`. Das ist eine eigene App: Die frühere Version (`net.devemperor.dictate.debug`) bleibt daneben installiert. Ihre Einstellungen lassen sich über „Sichern“ dort und „Wiederherstellen“ hier übernehmen.
- Für 64-Bit-Handys (arm64, zum Beispiel Galaxy S24)
- Neu: Oberfläche „Entwurf 3“, Welle und Wolke als schwebender Button (Welle ist Standard), Icon „Welle um die Welt“ mit Umschalter weiß/schwarz
- Behalten: Diktat, Spracheingabe für andere Tastaturen (zum Beispiel SwiftKey), schwebender Button, Datei transkribieren, Verlauf und Statistik, Offline-Spracherkennung
- Entfernt: Tastatur und Zubehör
- Signaturschlüssel: gleicher Debug-Schlüssel wie bei den früheren Versionen, SHA-256 `45e2792ddc9646037fb74aa01266686bef3f0e63c119f53ebedb32f64bd3e1dd`. Spätere Versionen von `app.diktat` lassen sich darüber installieren.
- SHA-256 der Datei: `965e1baeb8681bce7583eddbab5e94e63464004556f64ba2e7d699c973231e63`
